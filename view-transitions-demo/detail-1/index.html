Only this photo element carries view-transition-name: photo-1, matching the same name on the gallery card. Because the names match, the browser morphs the shared element between its old position/size and its new one instead of just cross-fading it.

The heading and this text have no view-transition-name, so they use the default root transition (a simple cross-fade) - proving a single element can be singled out for its own animation.
